## Multi-Project Routing

If the job contains `projects.json`, validate it with `~/.xoch/bin/project-scope.sh validate --scope [path]`, then identify the invoked repository and canonical primary job with `project-scope.sh role`. Read and write shared job artifacts through the primary job directory, run relative workflow helpers from the primary project root, make source changes only inside each listed owning repository, and run `~/.xoch/bin/context-sync.sh sync --scope [primary job]/projects.json` after shared context changes. Stop on validation or sync failure; never copy source files or `.xoch/work/current.json` between repositories.
